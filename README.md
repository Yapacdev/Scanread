Scanread — WEB APP

This is a normal local web app. It is NOT a Chrome extension.

To run open:
   http://localhost:8000


FEATURES
- Load PDF files from your computer
- PDF.js rendering
- Page navigation and zoom
- Search
- Bookmarks
- Resume position
- Reading progress
- Dark / sepia / light modes
- Font-size preference
- Browser text-to-speech
- Voice and speed selection
- Multiple books can be remembered using localStorage
